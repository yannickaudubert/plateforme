# Cockpit OS DSI Transverse

Local-first operator platform above Windows for knowledge, data, workflows, research, and AI-assisted operations.

## Core systems

- Obsidian
- NocoDB
- n8n
- Perplexica
- Open WebUI

## Repository purpose

This repo contains the codebase for the operator cockpit, not the external tools themselves.

## Guiding principles

- useful before fancy
- modular
- explicit adapters
- safe actions
- operator-first UX
- local-first architecture
